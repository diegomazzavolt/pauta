NOVA EDITORIA

Qual é o assunto?

Os canais deste bloco serão acompanhados juntos e alimentarão o mesmo assunto no jornal.

O último vídeo de cada canal será processado assim que você salvar. Depois, acompanharemos as novas publicações. Links repetidos são ignorados. Até 500 canais por bloco.
REDAÇÃO AUTOMÁTICA

A inteligência do jornal

A redação usa a API da OpenAI para analisar o texto, reunir os assuntos e escrever as matérias em português com referências aos vídeos.

A chave fica no servidor e não é enviada ao GitHub. As legendas serão enviadas à API para análise; o uso é cobrado na sua conta OpenAI. Sem essa configuração, o acompanhamento e o acervo continuam funcionando, mas as matérias aguardam redação.
